# Support 🛟

Choose the route that matches what you need so questions, defects, and security reports reach the right deck.

## Ask a usage question

Use the [🔥HADES🔥 Discord server](https://discord.gg/BpEGzWwGYf) for setup questions, deployment planning, and informal troubleshooting. Describe the preset, selected services, host platform, and command you ran.

Redact credentials, generated WireGuard files, application secrets, tokens, private URLs, and sensitive logs before sharing anything.

## Report a reproducible bug

Open a [Plundarr bug report](https://github.com/scottgigawatt/plundarr/issues/new?template=bug-report.md) when current source or a published Maraudarr image behaves incorrectly.

Include:

- The Plundarr commit or Maraudarr image tag.
- The selected preset and added or removed services.
- Your operating system, Docker version, and Docker Compose version.
- The exact command and a minimal reproduction.
- Sanitized logs or output.

## Request a documentation improvement

Open a [documentation request](https://github.com/scottgigawatt/plundarr/issues/new?template=documentation-enhancement.md) and identify the page, heading, command, or example that is unclear.

## Report a vulnerability

Do not use Discord or a public issue for vulnerability details. Follow the [security policy](SECURITY.md) and use GitHub private vulnerability reporting.

Plundarr is maintained by a small crew, so support is best effort. Clear reproductions and sanitized evidence make a safe answer much easier to chart.
